# 🏦 NOVA Bank — Mobile Banking App

## 📌 Overview

**NOVA Bank** is a modern mobile banking UI/UX concept designed to provide users with a simple, secure, and trustworthy banking experience.

The application focuses on making important financial information easy to understand while keeping essential banking actions quick and accessible.

## ✨ Features

- 🔐 Secure Sign In
- 💰 View Total Balance
- 📊 Monthly Spending Overview
- ⚡ Quick Banking Actions
- 📋 Transaction History
- 🔎 Search and Filter Transactions
- 💸 Transfer Money
- ✅ Review Transfer Details
- 🎉 Transfer Confirmation
- 💳 Account and Card Management
- 🔒 Security Settings
- 👤 Profile and Account Settings

## 📱 Screens

The design includes:

1. **Welcome & Sign In**
2. **Home Dashboard**
3. **Transactions**
4. **Transfer Money**
5. **Review Transfer**
6. **Transfer Success**
7. **Account & Profile**

## 🎨 Design Approach

The interface uses a clean and professional visual style suitable for a banking application.

The design focuses on:

- Clear information hierarchy
- Simple navigation
- Easy access to core banking actions
- Professional and trustworthy colors
- Consistent spacing and typography
- Minimal and modern UI components
- A short and clear money transfer flow

## 🎯 User Experience

The main goal of NOVA Bank is to allow users to quickly understand their financial status and complete common banking tasks without unnecessary steps.

The dashboard highlights the user's balance, spending information, recent transactions, and important actions such as transferring money.
